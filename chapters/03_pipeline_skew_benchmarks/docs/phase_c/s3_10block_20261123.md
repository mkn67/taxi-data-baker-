The paired bootstrap ratio against Baseline (10,000 fixed-seed resamples) is 1.019 [0.999–1.039] for AQE, 1.161 [1.138–1.202] for Salting, and 0.244 [0.221–0.254] for Spark auto. With the predeclared 5% practical threshold, AQE versus Baseline remains unresolved; Salting is slower and Spark auto faster in this session. Exact paired sign-flip p-values, Holm-adjusted across the three comparisons, are 0.326, 0.0059 and 0.0059 respectively. These intervals quantify this session and are not cross-session stability evidence.

All ten Spark auto final plans contain `BroadcastHashJoin`; all ten AQE plans contain `SortMergeJoin` and none show a skew split. The recorded AQE behavior must not be called skew partition splitting. Every measured run reports zero memory/disk spill at 1,500 MiB. The 1,024 MiB attempt (`app-20261123033419-0000`) ended after two blocks when its attached process was terminated. It was incomplete and used a different executor budget, so it is not pooled with this session; its event log and partial plans are retained separately.
