# Scripts Chương 1 — Khảo sát ban đầu

Thư mục này giữ script khảo sát dữ liệu được dùng ở giai đoạn đầu dự án:

- `01_explore_and_hotspot.py` — bản khảo sát lịch sử, còn cấu hình đường dẫn Spark cũ. Không dùng script này để tái tạo artifact P95 chính thức.

Hotspot P95 được dùng trong benchmark hiện được tạo và kiểm toán bởi pipeline làm sạch Silver tại [`../chapter_02/02_preprocess_and_audit.py`](../chapter_02/02_preprocess_and_audit.py). Các script Chương 2 và Chương 3 nằm trong thư mục tương ứng; dữ liệu vẫn được quản lý tập trung dưới `data/`.
