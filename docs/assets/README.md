# Quy ước ảnh trong project

- `readme/`: hình minh họa hiển thị trên README chính.
- `chapter4/`: bản PNG/SVG đã chuẩn bị để chèn vào bản thảo Chương 4.
- Hình được sinh trực tiếp từ dữ liệu và cần truy vết tới run được giữ cạnh artifact nguồn trong `data/zones/`, `data/benchmarks/` hoặc `data/gold/`. Các bản ở `docs/assets/` chỉ là hình trình bày khi script Chương 4 chủ động xuất bản sao.

Mỗi hình trong báo cáo cần có số hình, mô tả, nguồn dữ liệu/script và phạm vi run/tháng tương ứng. Xem [bản đồ Nội dung 1–4](../project_map_content_1_to_4.md) để tìm script tạo hình.
